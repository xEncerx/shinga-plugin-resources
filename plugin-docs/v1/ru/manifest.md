# Манифест плагина v1

[Создание плагина](README.md) · [Справочник Dart-скрипта](script.md)

`manifest.json` описывает плагин, задаёт версию API и путь к точке входа, запрашивает доступ к сети и определяет пользовательские настройки. Манифест разбирается без запуска скрипта.

## Файл и правила JSON

- Разместите `manifest.json` в корне пакета как обычный файл, не символическую ссылку.
- Используйте корректный JSON в UTF-8 с объектом в корне. Стандартный предел размера файла — 256 КиБ (262144 байта), включая пробелы и BOM; приложение может задать меньший предел.
- Допускается один BOM UTF-8 в самом начале. Второй BOM в начале не допускается.
- Имена полей и типы настроек чувствительны к регистру. Значения должны иметь указанный тип JSON; преобразований строк в числа и других неявных преобразований нет. Целые поля требуют целого значения, например `1`, а не `1.0`.
- **Неизвестные поля являются ошибкой**, в том числе внутри сетевых разрешений, настроек и вариантов выбора. Неизвестные разрешения и типы настроек также являются ошибками.
- **Необязательное поле можно опустить, но нельзя заменить на `null`.** Явный `null` недопустим во всех определённых полях манифеста, включая необязательные поля и значения по умолчанию. Элементы коллекций также не могут быть `null`.
- Используйте уникальные имена полей JSON. Не полагайтесь на проверку повторяющихся имён в исходном JSON. Уникальность элементов массивов и нормализованных локалей проверяется согласно правилам ниже.

## Полный пример

Пример нацелен на API, описанный в этой документации. Объявляйте только необходимые источнику настройки и домены.

```json
{
  "manifestVersion": 1,
  "id": "com.example.manga",
  "name": "Example Manga",
  "version": "1.0.0",
  "pluginApiVersion": 1,
  "entry": "index.dart",
  "icon": "https://example.com/favicon.ico",
  "permissions": {
    "network": {
      "hosts": ["api.example.com", "*.cdn.example.com"]
    }
  },
  "settings": [
    {
      "id": "searchPrefix",
      "type": "text",
      "label": {"en": "Search prefix"},
      "defaultValue": ""
    },
    {
      "id": "apiToken",
      "type": "secret",
      "label": {"en": "API token"},
      "description": {"en": "Optional token for **authenticated requests**."}
    },
    {
      "id": "adultContent",
      "type": "boolean",
      "label": {"en": "Adult content"},
      "defaultValue": false
    },
    {
      "id": "minimumRating",
      "type": "num",
      "label": {"en": "Minimum rating"},
      "defaultValue": 7.5
    },
    {
      "id": "contentLanguage",
      "type": "select",
      "required": true,
      "label": {"en": "Content language"},
      "defaultValue": "en",
      "options": [
        {"value": "en", "label": {"en": "English"}},
        {"value": "ja", "label": {"en": "Japanese"}}
      ]
    },
    {
      "id": "genres",
      "type": "multiSelect",
      "label": {"en": "Preferred genres"},
      "defaultValue": ["action"],
      "options": [
        {"value": "action", "label": {"en": "Action"}},
        {"value": "comedy", "label": {"en": "Comedy"}}
      ]
    }
  ]
}
```

## Поля корневого объекта

| Поле | Тип JSON | Обязательное | Если опущено / правило |
| --- | --- | --- | --- |
| `manifestVersion` | целое | Да | Только `1`. |
| `id` | строка | Да | ID плагина в нижнем регистре в форме reverse-DNS. |
| `name` | строка | Да | Имя для отображения пользователю, не пустое и не состоящее только из пробельных символов; не объект локализованного текста. |
| `version` | строка | Да | Версия выпуска плагина по SemVer 2.0.0. |
| `pluginApiVersion` | целое | Да | Положительная версия API; для этого руководства используйте `1`. |
| `entry` | строка | Да | Безопасный относительный путь скрипта внутри пакета. |
| `icon` | строка | Нет | Иконка отсутствует. Иначе — абсолютный URL изображения HTTP(S). |
| `permissions` | объект | Нет | Разрешения не запрашиваются. |
| `settings` | массив объектов | Нет | Настроек нет. |

### ID плагина

Используйте стабильный глобально уникальный ID, например `com.example.manga`:

- Не менее двух сегментов, разделённых точками; общая длина — не более 253 символов.
- Каждый сегмент содержит от 1 до 63 строчных ASCII-букв, цифр или дефисов внутри сегмента.
- Сегмент не может начинаться или заканчиваться дефисом. Заглавные и не-ASCII символы недопустимы.
- Автоматической обрезки пробелов и нормализации нет.

ID обозначает источник, но не удостоверяет личность издателя. См. [подпись](README.md#подпись).

### Версии

Эти поля имеют разное назначение:

- `manifestVersion` задаёт формат манифеста.
- `pluginApiVersion` задаёт API скрипта. Парсер манифеста принимает любое положительное целое, но приложение должно поддерживать именно эту версию, чтобы запустить скрипт.
- `version` обозначает выпуск плагина. Используйте [Semantic Versioning 2.0.0](https://semver.org/spec/v2.0.0.html), например `1.0.0`, `1.2.3-alpha.1` или `2.0.0+build.5`. Не используйте префикс `v` и ведущие нули в числовых компонентах версии и prerelease.

### Путь к точке входа

Для Dart-скрипта v1 используйте расширение в нижнем регистре `.dart`, например `index.dart` или `dist/index.dart`. Файл должен существовать по указанному пути с точным регистром символов. Неподдерживаемое расширение нельзя исполнить.

Правила пути:

- Путь относительный, разделитель — только `/`. Абсолютные пути, пути с диском, URL, `:` и обратные косые черты недопустимы.
- Запрещены пустые сегменты, сегменты `.` и `..`, а также завершающие точки или пробелы в любом сегменте.
- Запрещены ASCII управляющие символы U+0000–U+001F и символы `<`, `>`, `"`, `|`, `?`, `*`.
- Запрещены имена устройств Windows без учёта регистра: `CON`, `PRN`, `AUX`, `NUL`, `CLOCK$`, `CONIN$`, `CONOUT$`, `COM1`–`COM9`, `LPT1`–`LPT9`, а также `COM`/`LPT` с надстрочными цифрами `¹`, `²`, `³`. Проверяется имя до первой точки, поэтому `con.dart` тоже недопустим.

Исполняемый код автора может находиться только в файле точки входа; импортировать другие файлы пакета нельзя. См. [структуру скрипта](script.md#структура-скрипта).

### Иконка

`icon` должен быть абсолютным URL HTTP или HTTPS с непустым хостом. Путь URL должен оканчиваться, без учёта регистра, одним из расширений:

```text
.ico .gif .webp .png .jpg .jpeg .avif .bmp .svg .svgz .tif .tiff .apng
```

Проверяется расширение пути; query string не заменяет обязательное расширение файла изображения. Можно использовать favicon сайта, если она соответствует правилам.

## Локализованный текст

Подписи настроек и вариантов выбора, а также описания настроек — это объекты, сопоставляющие теги локалей строкам:

```json
{"en": "Content language", "en-GB": "Content language"}
```

- Укажите хотя бы одну локаль. Каждое значение должно быть строкой, не пустой и не состоящей только из пробельных символов; исходный текст сохраняется без обрезки пробелов.
- Поддерживается формат `language[-Script][-REGION]`: 2–8 ASCII-букв языка, необязательный четырёхбуквенный script и необязательный регион из двух букв или трёх цифр. Используйте `-`, а не `_`; варианты и расширения не поддерживаются.
- Теги нормализуются: `EN` → `en`, `hans` → `Hans`, `us` → `US`; числовой регион сохраняется. Разные ключи, ставшие одинаковыми после нормализации, являются ошибкой, например `EN` и `en` в одном объекте.
- Английская локаль не обязательна. При выборе текста проверяются точная локаль, затем language-script, если в запрошенной локали есть и script, и region, затем language, `en` и, наконец, первый тег после лексикографической сортировки нормализованных локалей.

Описания содержат исходный Markdown, максимум **4000 пользовательских символов Unicode (расширенных графемных кластеров) на локаль включительно**. Текст сохраняется; синтаксис Markdown не проверяется. Используйте простой текст и выделение: raw HTML, изображения и интерактивное содержимое не поддерживаются, ссылки не открываются.

Для подписей настроек и вариантов выбора отдельного лимита в 4000 символов нет, но действует общий предел размера манифеста. Эти правила отличаются от [лимитов локализованных моделей](script.md#лимиты-моделей), возвращаемых скриптом.

## Разрешения

В манифесте v1 поддерживается только `permissions.network`:

```json
{"permissions": {"network": {"hosts": ["api.example.com", "*.cdn.example.com"]}}}
```

`network` должен быть объектом с обязательным массивом строк `hosts`. Если сетевое разрешение отсутствует или список хостов пуст, сетевой доступ не запрашивается. Не добавляйте разрешения для storage, logger или settings.

Правила для шаблонов хостов:

- Только ASCII-имена хостов; они нормализуются в нижний регистр. Не указывайте схему, порт, путь, query, fragment или данные пользователя.
- Максимум 253 символа без начального `*.`. Каждый сегмент между точками имеет длину 1–63 символа и содержит буквы, цифры или дефисы внутри сегмента; пустые сегменты, начальные/конечные дефисы и завершающая точка запрещены.
- Допускается только один wildcard в начале `*.`. `*.example.com` соответствует `cdn.example.com` и `a.cdn.example.com`, но не `example.com`.
- Шаблона для разрешения всех хостов нет. Повторяющиеся после перевода в нижний регистр шаблоны — ошибка; `example.com` и `*.example.com` различаются и могут быть указаны оба.
- Синтаксическая корректность хоста не гарантирует его доступность и не разрешает адреса частной или локальной сети. Ограничения HTTP во время выполнения проверяются отдельно.

**Объявление хоста запрашивает доступ, но не предоставляет его.** Каждый запрос и редирект должен соответствовать и хостам из манифеста, и хостам, одобренным для установки. Запрашивайте только домены, к которым плагин действительно обращается. См. [разрешения HTTP и редиректы](script.md#url-разрешения-и-заголовки).

## Настройки

Настройки — это статическая пользовательская конфигурация, а не динамическая [схема фильтров поиска](script.md#поиск). Приложение может показывать их, не запуская скрипт. Эффективные значения доступны через `context.settings`.

Каждая настройка принимает общие поля:

| Поле | Тип JSON | Обязательное | Если опущено / правило |
| --- | --- | --- | --- |
| `id` | строка | Да | Идентификатор для скрипта, не пустой и не состоящий только из пробельных символов. |
| `type` | строка | Да | `text`, `secret`, `boolean`, `num`, `select` или `multiSelect`. |
| `label` | локализованный текст | Да | Подпись для пользователя. |
| `description` | локализованный Markdown | Нет | Описание отсутствует. |
| `required` | boolean | Нет | `false`. |

ID настроек уникальны в пределах манифеста. ID и значения вариантов сравниваются точно, с учётом регистра; пробелы в сохранённых значениях не обрезаются.

### Типы настроек и значения по умолчанию

| Тип | Тип значения | `defaultValue` | Тип чтения в скрипте |
| --- | --- | --- | --- |
| `text` | строка | Необязательно; при отсутствии значения по умолчанию нет. Пустая строка допустима. | `String` |
| `secret` | секретная строка | **Запрещено**, включая `null` и пустую строку. | `String` |
| `boolean` | boolean | Необязательно; по умолчанию `false`. | `bool` |
| `num` | конечное число | Необязательно; значение по умолчанию отсутствует. Допустимы целые и дробные числа. | `num` |
| `select` | строка со значением одного варианта | Необязательно; должна точно совпадать с объявленным вариантом. | `String` |
| `multiSelect` | массив строк со значениями вариантов | Необязательно; каждое значение должно быть объявлено, повторы запрещены. Пустой массив допустим. | `List<String>` |

`options` требуется только для `select` и `multiSelect`; для остальных типов оно недопустимо. У секретной настройки нет жёстко заданного значения: его предоставляет пользователь. **Не помещайте токены, пароли или закрытые ключи подписи в манифест или скрипт.**

### Варианты выбора

Для `select` и `multiSelect` требуется непустой список `options`. Каждый объект содержит ровно:

| Поле | Тип JSON | Обязательное | Правило |
| --- | --- | --- | --- |
| `value` | строка | Да | Строка, не пустая и не состоящая только из пробельных символов; уникальна в пределах настройки. Это сохраняемое значение. |
| `label` | локализованный текст | Да | Подпись для отображения. |

Подпись — не сохраняемое значение. При изменении подписи стабильный `value` можно оставить прежним.

### Обязательные значения и доступ из скрипта

`required: true` не требует наличия значения по умолчанию в манифесте. До вызова плагина должно существовать допустимое эффективное значение; корректное значение по умолчанию может удовлетворять этому требованию. `false`, `0`, `""` и `[]` считаются значениями, а не отсутствием. Для обязательного секрета нужно предоставить значение, поскольку задать default нельзя.

Неустановленное необязательное значение без default читается как `null`. Получайте настройки по ID и с точным типом из таблицы, например:

```dart
final token = await context.settings.get<String>('apiToken');
final minimum = await context.settings.get<num>('minimumRating');
```

См. [настройки скрипта](script.md#настройки), чтобы узнать об их snapshot-семантике и ошибках. После изменения манифеста заново создайте [подпись](README.md#подпись) плагина.
